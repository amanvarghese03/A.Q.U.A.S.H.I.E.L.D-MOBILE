System Overview

Project A.Q.U.A.S.H.I.E.L.D. (Automated Flood Alerting and Soil Saturation Management System) is an advanced physical computing and software framework designed to prevent urban and localized flooding through predictive AI modeling, real-time sensor fusion, and automated drainage control.

Developer & Team

Developer: Aman Varghese

Institution: Class XI-B, UIS

Project Mentor: Mr. Philip Varghese

Features a multi-threaded Python PyQt5 SCADA desktop engine linked via serial to an Arduino microcontroller, supported by remote mobile telemetry web views.
